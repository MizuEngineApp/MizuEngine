## Что нового

Патч со звуками сообщений.

- **Новый звук входящих — «Fears To Fathom Message».** Выбрать его можно в «Настройки» → «Звук» → звук входящих сообщений.
- **«Звук Telegram» для входящих** — новый звук вместо старого «Как в Telegram».
- **Новый звук отправки «Как в Telegram».**
- **Новый «Дзинь (как у iPhone)».**
- Если у тебя уже был выбран один из этих звуков, он заменится сам — ничего переключать не нужно.

## What's new

A small patch with new message sounds.

- **New incoming sound — "Fears To Fathom Message".** Pick it in *Settings* → *Sound* → incoming message sound.
- **"Telegram sound" for incoming messages** — a new sound replaces the old "Telegram-style" one.
- **New "Telegram-style" send sound.**
- **New "Ding (iPhone-style)".**
- If you already had one of these sounds selected, it updates on its own — nothing to switch.
